# Nobody Is Coming To Save You

A 69 s dark, educational and motivational motion film built with HyperFrames (HTML + GSAP, rendered to MP4).

| Deliverable | File |
|---|---|
| Reel master, 1080×1920, 60 fps | `renders/final_9x16.mp4` |
| Captions | `captions.srt` |
| Thumbnail, 1080×1920 (scene-4 hero frame plus title) | `thumbnail/thumbnail.png` |

## Structure

- `index.html` is the 9:16 root. It holds 7 scene hosts, the caption track, the texture overlay and the audio mix.
- `compositions/s1-hook.html` … `s7-end.html` hold one scene each. Every scene carries a `@media (orientation: landscape)` layout.
- `compositions/captions.html` and `compositions/texture.html` are **generated**. Edit `tools/build_captions.py` and `tools/build_texture.py` instead.
- `assets/audio/` holds the voiceover (`vo.wav`, Kokoro `am_michael`), its word timings (`words.json`), the score and SFX stems, and the mastered `mix.wav`.
- `../nobody-is-coming-16x9/` is an optional 16:9 root, generated by `tools/make_16x9.sh`. It is not rendered: this film ships as a 9:16 Reel only.

## Rebuild

`build_audio.py` needs `numpy` and `soundfile`. Run every command from this folder.

Rebuild the score, SFX and ducked mix:

```bash
python tools/build_audio.py
```

Master the mix to about −14 LUFS with true peak ≤ −1 dBTP:

```bash
./tools/master.sh
```

Rebuild the audio-reactive grain and light leak:

```bash
python tools/build_texture.py
```

Rebuild the burned-in captions and `captions.srt`:

```bash
python tools/build_captions.py
```

Regenerate the 16:9 project:

```bash
./tools/make_16x9.sh
```

Run the checks:

```bash
npx hyperframes check
```

Render the 60 fps reel:

```bash
npx hyperframes render --quality delivery --fps 60 -o renders/final_9x16.mp4
```

To change the end-card sign-off, edit the `handle` variable on `index.html`.
