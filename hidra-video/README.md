# HIDRA — proyecto de marketing (Yassir)

An 88-second, 1920×1080 YouTube video built with [HyperFrames](https://hyperframes.heygen.com).
It presents **HIDRA**, a reusable smart water bottle, and its marketing plan:
problem → product → features → target audience → price → distribution → promotion → sales goal.

## Files
| Path | What it is |
| --- | --- |
| `index.html` | Host composition (generated by `scripts/build-index.py`; edit the script, not this file) |
| `compositions/s01…s10-*.html` | One sub-composition per scene |
| `compositions/fx-*.html` | Shared paper background, white bloom, dark iris, film grain (generated) |
| `assets/js/hidra3d.js` | Three.js kit: the 3D HIDRA bottle and the clay icons |
| `assets/img/*.png` | 3D stills rendered from that kit (`scripts/render-stills.mjs`) |
| `assets/vo/`, `assets/narration.wav` | Spanish voiceover (Kokoro `em_alex`, local) |
| `assets/music.wav` | Music bed synthesized by `scripts/gen-music.py` |
| `assets/sfx/` | Sound effects (Pixabay licence, see `assets/sfx/CREDITS.md`) |
| `scripts/timing.json` | Scene starts and voice cue times: the single source of timing |
| `BRIEF.md`, `STORYBOARD.md`, `frame.md` | Brief, scene plan, design spec |

## Rebuild
```bash
python3 scripts/gen-vo.py em_alex 1.0      # voice lines (edit scripts/vo-lines.json)
python3 scripts/build-narration.py         # place lines on the timeline
python3 scripts/gen-music.py               # music bed
python3 -m http.server 8765 --bind 127.0.0.1 &  # then: node scripts/render-stills.mjs
python3 scripts/build-index.py             # host + fx layers (keeps the music carve)
npx hyperframes check
npx hyperframes render -o renders/hidra-yassir.mp4
```
To use a female Spanish voice instead, run `gen-vo.py ef_dora 1.0`, then rebuild the narration.
