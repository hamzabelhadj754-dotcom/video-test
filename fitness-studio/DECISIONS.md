# Same Muscle: studio edition

## Brief
User reference: a Notion-style ad (soft light-grey studio, glossy 3D icon objects, pastel cards, kinetic type with
one accent word, an accent line carrying the eye between objects, smooth camera with blur dissolves, one dark beat).
Goal: that visual language in the fitness niche. User choices: soft light grey background; topic kept
("light weights build muscle when taken close to failure").

## Design system
- Background: radial studio sweep #F8F8F8 -> #ECECEC -> #DEDEDE; dark beat #0E0E10.
- Accent #FF4D1A (one per line). Pastels: mint #DCF4E2, peach #FFE6D8, rose #FFDCD5, lilac #E7E4FF.
- Type: Geist variable, 450-680, tracking -0.035em, centered like the reference.
- 3D: three.js glossy dumbbells (MeshPhysical clearcoat, chrome handle, RoomEnvironment reflections), soft drop shadows.
- Motion: spring entrances (overshoot bezier), blur-rise text, camera push, slide-with-blur, 4x sub-frame motion blur.

## Log
- v01: full 20s film with synthesized sound.
- Brand: gainsdom (wordmark only on end card; no logo file yet).
