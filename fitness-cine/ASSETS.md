# Gainsdom cinematic: assets
- All objects (dumbbell, muscle-fibre bundle, weight plate, light ring) are modelled and lit in code with Three.js r147 (MIT, `assets/vendor/three.min.js`). No stock images or footage.
- Haze, light shafts, grain, bloom and reflections are made in code (SVG noise, CSS).
- Fonts: Bebas Neue, Anton, Inter (SIL OFL).
